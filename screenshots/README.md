# Screenshots

Add only sanitized screenshots.

Recommended screenshots:

- Portainer dashboard with sensitive fields hidden
- Container list with generic names
- Stack view with environment values hidden
- Docker network view with IP addresses hidden
- Volume list with real host paths hidden
- Public portfolio homepage
- UniFi interface with device, IP, MAC and location data hidden

Before publishing, hide:

- IP addresses
- Hostnames
- Domains
- Email addresses
- Container IDs
- Environment variables
- MAC addresses
- Volume paths
- Tokens
- Usernames
- Notifications
- Device identifiers
- Personal files
